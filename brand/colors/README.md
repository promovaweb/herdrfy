# Paleta do Herdrfy

| Família | Base | Papel |
| --- | --- | --- |
| Petróleo | `#00161E` | estrutura, texto e superfícies escuras |
| Turquesa | `#2AD5BE` | painéis, terminal e vínculo com a Promovaweb |
| Magenta | `#E0457B` | agente em foco e cursor ativo |

O símbolo usa magenta `#E0457B` (500) sobre petróleo e `#C42A63` (600) na
versão para fundo claro. A escala do acento segue a lógica da escala `pink`
do Tailwind, ajustada para manter esses dois valores.

No light mode, use acento textual `#A41F51`. No dark mode, use `#F6A8C4`.
A escala completa e os estados ficam em `palette.json`; os pares aprovados
ficam em `../accessibility.md`.
